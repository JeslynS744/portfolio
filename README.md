# Jeslyn Nivedhitha S — Developer Portfolio

Production-ready, responsive, zero-config developer portfolio web application built with **Next.js 13 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Lucide Icons**.

## 🚀 Quick Start (Local Development)

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev

# 3. Open browser
http://localhost:3000
```

## 📦 Deployment on Vercel

This repository is optimized for 1-click zero-config deployment on Vercel:

1. Import this repository into Vercel.
2. Select Framework Preset: **Next.js**.
3. Build Command: `npm run build`.
4. Output Directory: `.next`.
5. Click **Deploy**.

## 🛠 Tech Stack

- **Framework:** Next.js 13 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS & Glassmorphism design tokens
- **Icons:** Lucide React
- **Theme:** Dark / Light mode toggle
- **SEO:** OpenGraph & Twitter Cards
